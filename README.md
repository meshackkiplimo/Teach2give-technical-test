# Teach2Give Technical Test

The project was done with javascript programming language

## Challenges

### 1. FizzBuzz
Prints numbers from 1 to 100 with the following rules:
 Prints "Fizz" for numbers divisible by 3
 Prints "Buzz" for numbers divisible by 5
 Prints "FizzBuzz" for numbers divisible by both 3 and 5
 Prints the number itself for all other cases

### 2. Fibonacci Sequence
Generates the Fibonacci sequence up to 100. The sequence is created where each number is the sum of the previous two numbers.

### 3. Power of Two
Determines if a given integer is a power of two. Returns true if the input number can be expressed as 2^n for some integer n > 0, false otherwise.

### 4. Capitalize Words
Takes a string input and capitalizes the first letter of each word while converting the rest of the letters to lowercase.

### 5. Reverse Integer
Takes an integer as input and returns an integer with reversed digit ordering.

### 6. Count Vowels
Counts the number of vowels (a, e, i, o, u) in a given sentence, case-insensitive.

## Running the Code

1. Ensure you have Node.js installed on your system
2. Clone this repository
3. Run the code using Node.js:
```bash
node index.js
```
